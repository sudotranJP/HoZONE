# 一人暮らしのあなたに、HoZONE。

## \[令和８年度システム設計実習個人取組作品]

HoZONEは、一人暮らしのあなたに最適。本格派ではなく、ざっくりと管理。ざっくりといきましょう。

既存の食材がどれほどあるのか、リストアップされていたら便利だと思いませんか？

さらに、買いだめして冷凍庫に入れて、そのまま放置...なんていうことを防ぐ、冷凍庫別枠管理機能も搭載。冷凍焼けを防ぎます。

##### 常温・冷蔵庫、そして冷凍庫の食品を記録できる！

基本的に入れたままなら劣化する！放置すれば大変なことに。



##### 冷凍庫に入れた、冷凍食品でない食品を記録できる！

消費期限や賞味期限が近いけど安い！でも食べる予定がない、でも買っちゃう...をしてしまう貴方。

冷凍庫に入れればしばらく放置できるのでよくやると思いますが、それ、ちゃんと食べていますか？

食べずに放置すると、冷凍庫特有の、あのニオイが付いてしまいますよ！

だからこそ冷凍庫に入れた日数をカウント！日にちがたつと色が変わる！
